Proyecto Front-End

Proyecto desarrollado como parte de mi formación en Desarrollo Front-End, aplicando HTML, CSS y JavaScript para crear una interfaz web responsive y funcional.

Tecnologías utilizadas:
HTML5 | CSS3 | JavaScript | Git | GitHub

El proyecto fue desarrollado como práctica integral de desarrollo Front-End, trabajando sobre la estructura, estilos, componentes visuales e interacción de una página web.

Se priorizó:
Diseño responsive
Organización semántica del contenido
Estructura y estilos con HTML y CSS
Interacciones mediante JavaScript
Adaptación a distintos tamaños de pantalla

Aprendizajes:
Durante el desarrollo trabajé conceptos fundamentales de Front-End, incluyendo:
Maquetación web
Diseño responsive
Manipulación del DOM
Eventos e interacción con JavaScript
Organización de archivos
Control de versiones con Git y GitHub
Deploy de sitios web
